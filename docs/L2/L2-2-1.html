1 📊 L2-2 시계열 바이탈 신호 고급 분석

본 워크북은 ECG, PPG 등 시계열 바이탈 신호의 고급 전처리, 특징 추출 및 머신러닝 모델링을 포함합니다. 이론적 기반과 실무 문제 해결 능력을 동시에 강화할 수 있도록 설계되었습니다. 분석가는 웨이블릿 변환, HRV 분석, 그리고 적응형 필터링을 고려해야 합니다.

진행률: 0% (분석 시작) 🔄
활용도: 상위권 대학 학부 4학년 전공 심화

2 🧬 L2-2 시계열 바이탈 신호 고급 분석

2.1 🧭 학습 목표 (Learning Outcomes)

이 워크북을 통해 학습자는 다음을 실습하게 됩니다:

  • 웨이블릿 변환을 활용한 고급 노이즈 제거 및 적응형 필터링 구현
  • R-peak 검출 알고리즘을 통한 HRV(Heart Rate Variability) 전체 스펙트럼 분석
  • 시간/주파수/비선형 도메인에서의 다차원 특징 추출 및 융합

2.2 🧩 실습 개요

  • 데이터: MIT-BIH Arrhythmia Database (PhysioNet)
  • 목표: ECG 신호의 고급 전처리, HRV 분석 및 부정맥 분류
  • 사용 기술: PyWavelets, WFDB, SciPy, Scikit-learn, HRV 라이브러리
  • 제약 조건:
    1. 최소 3가지 이상의 전처리 기법을 점진적으로 적용하여 성능 개선 정량화
    2. 시간/주파수/비선형 도메인 각각에서 5개 이상의 특징 추출

2.3 🔄 전체 실습 흐름

단계 주요 작업 내용 주요 도구/스킬 결과물
1단계 데이터 로드 및 탐색 WFDB 원본 ECG 파형
2단계 긴 호흡 전처리 PyWavelets, SciPy 단계별 개선된 파형
3단계 긴 호흡 특징추출 HRV, Entropy 다차원 특징 벡터
4단계 긴 호흡 모델링 SVM, XGBoost 최적화된 분류기
5단계 성능 평가 Scikit-learn 혼동 행렬, ROC
6단계 모델 해석 SHAP 특징 중요도
7단계 외부 검증 PTB-XL 일반화 성능
8단계 결과 리포트 작성 Matplotlib 종합 보고서

2.4 📝 사전 필요

이 워크북은 다음 기술/개념을 선행 학습한 학습자를 대상으로 합니다:

  • 기본 신호처리 이론 (샘플링, 필터링, 푸리에 변환)
  • Python NumPy/Pandas 중급 활용
  • 머신러닝 기초 (분류, 교차검증)

2.5 🗂 사용 데이터 설명

📌 데이터셋: MIT-BIH Arrhythmia Database
📌 출처: PhysioNet
📌 배경: 47명의 환자로부터 수집된 48개의 30분 ECG 기록, 360Hz 샘플링

변수명 설명
ECG Lead II 표준 리드 II ECG 신호
Annotations 전문가가 라벨링한 부정맥 주석
R-peak locations QRS 복합체의 R파 위치
Beat types N(정상), V(심실), A(심방) 등 박동 유형

def basic_preprocessing(signal_data, fs):
    """기본 대역통과 필터링"""
    nyquist = fs / 2
    low_cutoff = 0.5 / nyquist
    high_cutoff = 40 / nyquist

    b, a = signal.butter(4, [low_cutoff, high_cutoff], btype='band')
    filtered = signal.filtfilt(b, a, signal_data)

def wavelet_denoise(signal_data, wavelet='db4', level=9):
    """웨이블릿 변환 기반 노이즈 제거"""
    coeffs = pywt.wavedec(signal_data, wavelet, level=level)

    # 적응형 임계값 계산
    sigma = np.median(np.abs(coeffs[-1])) / 0.6745
    threshold = sigma * np.sqrt(2 * np.log(len(signal_data)))

    # Soft thresholding
    coeffs_thresh = []
    for i, coeff in enumerate(coeffs):
        if i == 0:  # Approximation coefficients 보존
            coeffs_thresh.append(coeff)
        else:
            coeffs_thresh.append(pywt.threshold(coeff, threshold, mode='soft'))

    # 신호 재구성
    denoised = pywt.waverec(coeffs_thresh, wavelet)

    return denoised[:len(signal_data)]

# 웨이블릿 노이즈 제거 적용

def adaptive_filter(signal_data, window_length=51, polyorder=3):

def baseline_wander_removal(signal_data, fs):
    """기저선 변동 제거 (의료 도메인 특화)"""
    # 0.5Hz 이하 성분 제거
    nyquist = fs / 2
    cutoff = 0.5 / nyquist
    b, a = signal.butter(4, cutoff, btype='high')
    corrected = signal.filtfilt(b, a, signal_data)

    return corrected

def powerline_interference_removal(signal_data, fs, freq=60):
    """전력선 간섭 제거 (50/60 Hz)"""
    nyquist = fs / 2
    notch_freq = freq / nyquist
    q_factor = 30
    b, a = signal.iirnotch(notch_freq, q_factor)
    filtered = signal.filtfilt(b, a, signal_data)

    return filtered

def extract_basic_features(ecg_signal, fs):

# 고급 특징 추출 (시간/주파수/비선형 도메인)
def extract_advanced_features(ecg_signal, fs):
    """다차원 고급 특징 추출"""
    features = {}

    # R-peak 검출
    rpeaks = nk.ecg_peaks(ecg_signal, sampling_rate=fs)[1]['ECG_R_Peaks']
    rr_intervals = np.diff(rpeaks) / fs * 1000

    # 시간 도메인 특징 (확장)
    time_features = get_time_domain_features(rr_intervals)
    features.update(time_features)

    # 주파수 도메인 특징
    freq_features = get_frequency_domain_features(rr_intervals)
    features.update(freq_features)

    # 비선형 특징
    poincare_features = get_poincare_plot_features(rr_intervals)
    features.update(poincare_features)

def evaluate_model_performance():
    """모델 성능 종합 평가"""
    # 시뮬레이션된 예측 결과
    np.random.seed(42)
    y_true = np.random.randint(0, 2, 100)
    y_pred = np.random.randint(0, 2, 100)
    y_prob = np.random.random(100)

    # 기본 메트릭
    from sklearn.metrics import accuracy_score, precision_score, recall_score, f1_score

    metrics = {
        'Accuracy': accuracy_score(y_true, y_pred),
        'Precision': precision_score(y_true, y_pred),
        'Recall': recall_score(y_true, y_pred),
        'F1-Score': f1_score(y_true, y_pred),
        'AUC-ROC': roc_auc_score(y_true, y_prob)
    }

    # 도메인 특화 메트릭
    tn = np.sum((y_true == 0) & (y_pred == 0))
    fp = np.sum((y_true == 0) & (y_pred == 1))
    fn = np.sum((y_true == 1) & (y_pred == 0))
    tp = np.sum((y_true == 1) & (y_pred == 1))

    specificity = tn / (tn + fp)
    npv = tn / (tn + fn)  # Negative Predictive Value

    metrics['Specificity'] = specificity
    metrics['NPV'] = npv

    # 임상적 의미
    prevalence = np.mean(y_true)
    nnt = 1 / (recall_score(y_true, y_pred) * prevalence)  # Number Needed to Treat

    metrics['NNT'] = nnt

    return metrics, y_true, y_pred, y_prob
