oldpeak 운동 대비 ST depression
slope peak exercise ST segment 기울기
ca 주요 혈관 수 (0-3)
thal 탈라세미아 (3=정상, 6=고정, 7=가역)
target 심장질환 여부 (1=질환, 0=정상)

## 2.2 고급 전처리 - MICE (Multiple Imputation by Chained Equations)
print("\n### 2.2 고급 전처리 - MICE 대체")
print("=" * 50)

# MICE 적용
df_mice = df.copy()

# MICE Imputer 생성
mice_imputer = IterativeImputer(random_state=42, max_iter=10)

# 수치형 변수에만 MICE 적용
numeric_features = df_mice.select_dtypes(include=[np.number]).columns
df_mice[numeric_features] = mice_imputer.fit_transform(df_mice[numeric_features])

print(f"MICE 적용 후 결측치: {df_mice.isnull().sum().sum()}")
print(f"데이터 손실 없이 모든 {len(df_mice)} rows 유지")

# MICE 적용된 데이터로 성능 측정
X_mice = df_mice.drop('target', axis=1)
y_mice = df_mice['target']
X_train_mice, X_test_mice, y_train_mice, y_test_mice = train_test_split(
    X_mice, y_mice, test_size=0.2, random_state=42, stratify=y_mice
