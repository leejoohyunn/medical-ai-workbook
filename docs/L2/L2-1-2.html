본 워크북은 전자건강기록(EHR) 데이터를 활용하여 당뇨병 환자의 재입원 위험을 예측하는 머신러닝 파이프라인을 구축합니다. 이론적 기반과 실무 문제 해결 능력을 동시에 강화할 수 있도록 설계되었습니다. 분석가는 의료 데이터의 특성을 고려한 전처리와 해석 가능한 모델 구축을 고려해야 합니다.

2.1 🧭 학습 목표 (Learning Outcomes)

이 워크북을 통해 학습자는 다음을 실습하게 됩니다:

  • EHR 데이터의 복잡한 결측치 패턴을 이해하고 MICE를 활용한 고급 대체 기법 적용
  • 의료 데이터의 클래스 불균형 문제를 다양한 방법으로 해결하며 성능 변화 관찰
  • Baseline 모델부터 앙상블까지 ’긴 호흡’으로 성능을 점진적으로 개선
  • SHAP을 활용한 모델 해석으로 임상적 의사결정 지원 가능성 탐구

2.2 🧩 실습 개요

  • 데이터: Diabetes 130-US hospitals dataset (1999-2008)
  • 목표: 30일 이내 재입원 위험이 높은 당뇨병 환자 예측
  • 사용 기술: pandas, scikit-learn, imbalanced-learn, SHAP, Optuna
  • 제약 조건:
    1. 의료 데이터 특성상 False Negative를 최소화하는 방향으로 최적화
    2. 모델의 임상적 해석 가능성을 유지하면서 성능 개선

2.7.1 1.1 기본 데이터 로드

💡 메모리에서 바로 ZIP 파일 열기 (requests + zipfile)

UCI 저장소의 ZIP 파일을 로컬에 저장하지 않고, requests로 다운로드한 응답을 io.BytesIO와 zipfile.ZipFile을 이용해 메모리 상에서 바로 연다. 이렇게 하면 중간에 파일을 디스크에 쓰지 않고도 ZIP 압축 내부의 콘텐츠를 바로 다룰 수 있다.

이 ZIP 압축 안에는 CSV 파일이 두 개 들어 있기 때문에, URL을 그대로 pd.read_csv()에 넘기면 어느 파일을 읽어야 할지 몰라 에러가 발생한다. 따라서 먼저 z.namelist()로 ZIP 내부의 파일 목록을 확인한 뒤, z.open('dataset_diabetes/diabetic_data.csv')처럼 원하는 파일만 지정해서 pd.read_csv()로 읽어오도록 한다.

Code 
import pandas as pd
import requests, zipfile, io

url = "https://archive.ics.uci.edu/ml/machine-learning-databases/00296/dataset_diabetes.zip"

# 1) zip 파일을 메모리로 가져오기
r = requests.get(url)
z = zipfile.ZipFile(io.BytesIO(r.content))

# 2) zip 안 파일 이름 확인 (선택)
print(z.namelist())

# 3) 원하는 csv만 읽기
data = pd.read_csv(z.open('dataset_diabetes/diabetic_data.csv'))

# 의료 도메인 지식을 활용한 파생 변수 생성
def create_medical_features(df):
    """의료 도메인 지식 기반 특징 생성"""
    df_new = df.copy()

    # 1. 의료 서비스 집중도 (총 의료 서비스 이용량)
    df_new['total_services'] = (
        df_new['num_lab_procedures'] +
        df_new['num_procedures'] +
        df_new['num_medications']
    )

    # 2. 입원 복잡도 지수 (입원 기간 대비 시술/검사 수)
    df_new['complexity_index'] = (
        (df_new['num_procedures'] + df_new['num_lab_procedures']) /
        (df_new['time_in_hospital'] + 1)  # +1로 0으로 나누기 방지
    )

    # 3. 약물 부담 지수 (입원 기간 대비 약물 수)
    df_new['medication_burden'] = (
        df_new['num_medications'] /
        (df_new['time_in_hospital'] + 1)
    )

    # 4. 과거 입원 이력 (응급/외래/입원 횟수 합)
    df_new['admission_history'] = (
        df_new['number_emergency'] +
        df_new['number_inpatient'] +
        df_new['number_outpatient']
    )

    # 5. 진단 다양성 (unique 진단 수)
    df_new['diagnosis_diversity'] = df_new['number_diagnoses']

    return df_new

    vif_data = pd.DataFrame()

2.10.3 4.3 임상적 의미의 메트릭

Code 
# 임상적 의미 있는 메트릭 계산
def calculate_clinical_metrics(y_true, y_pred, y_pred_proba):
    """임상적 의미를 가진 메트릭 계산"""

    tn, fp, fn, tp = confusion_matrix(y_true, y_pred).ravel()

    # Sensitivity (Recall) - 실제 재입원 환자를 찾는 능력
    sensitivity = tp / (tp + fn)

    # Specificity - 재입원하지 않을 환자를 정확히 분류
    specificity = tn / (tn + fp)

    # PPV (Positive Predictive Value) = Precision
    ppv = tp / (tp + fp)

    # NPV (Negative Predictive Value)
    npv = tn / (tn + fn)

    # NNT (Number Needed to Treat) - 한 명을 정확히 예측하기 위해 검사해야 할 환자 수
    nnt = 1 / (sensitivity * (fp + tp) / (tp + fp + tn + fn)) if tp > 0 else np.inf

    return {
        'Sensitivity (재입원 탐지율)': sensitivity,
        'Specificity (정상 분류율)': specificity,
        'PPV (양성 예측도)': ppv,
        'NPV (음성 예측도)': npv,
        'NNT (검사 필요 수)': nnt
    }

clinical_metrics = calculate_clinical_metrics(y_val, y_pred_ensemble, y_pred_proba_ensemble)

print("🏥 임상적 성능 메트릭:")
for metric, value in clinical_metrics.items():
    if metric == 'NNT (검사 필요 수)':
        print(f"  - {metric}: {value:.1f}명")
    else:
        print(f"  - {metric}: {value:.3f} ({value*100:.1f}%)")
