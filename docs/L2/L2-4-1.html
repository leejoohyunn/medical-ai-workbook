2.1 🧭 학습 목표 (Learning Outcomes)

이 워크북을 통해 학습자는 다음을 실습하게 됩니다:

  • PubMed 의학 논문 초록 데이터의 구조를 이해하고 탐색적 데이터 분석(EDA)을 수행할 수 있다
  • 의학 텍스트에 특화된 전처리 파이프라인(토큰화, 불용어 제거, 의학 용어 정규화)을 구축할 수 있다
  • BoW에서 TF-IDF까지 텍스트 벡터화 기법의 원리를 이해하고 적용할 수 있다
  • Naive Bayes, Logistic Regression, 앙상블 모델을 점진적으로 구축하며 성능을 개선할 수 있다
  • 텍스트 분류 모델의 해석 기법(Feature Importance, Coefficient 분석)을 적용할 수 있다

2.2 🧩 실습 개요

  • 데이터: PubMed Medical Abstracts (Kaggle 공개 샘플)
  • 목표: 의학 논문 초록을 기반으로 질병 카테고리(심혈관, 신경계, 종양학 등)를 자동 분류
  • 사용 기술: NLTK, Scikit-learn (TF-IDF, LogisticRegression, MultinomialNB), Optuna
  • 제약 조건: (L2 응용)
    1. 모든 전처리 및 모델링은 점진적 개선(‘긴 호흡’)을 따름
    2. 각 단계의 성능 변화를 정량적으로 비교
    3. 의학 도메인 특화 전처리 기법 적용 필수

2.3 🔄 전체 실습 흐름

단계 주요 작업 내용 주요 도구/스킬 결과물
1단계 데이터 로드 및 탐색 pandas, matplotlib 데이터 분포 시각화, 클래스 불균형 확인
2단계 텍스트 전처리 (긴 호흡) NLTK, re, 의학 용어 사전 정제된 텍스트 코퍼스

import pandas as pd

def load_medical_text_dat(path):
    rows = []

    with open(path, "r", encoding="utf-8", errors="ignore") as f:
        for line in f:
            line = line.strip()
            if not line:
                continue

            # 핵심: 첫 번째 TAB 기준으로만 split
            parts = line.split("\t", 1)
            if len(parts) != 2:
                continue

            label, text = parts

            # label이 숫자가 아니면 버림 (깨진 row 방어)
            if not label.isdigit():
                continue

            rows.append({
                "condition": int(label),
                "abstract": text.strip()
            })

    return pd.DataFrame(rows)

2.9.5 3.3 하이퍼파라미터 튜닝 (Optuna)

Optuna를 사용하여 TF-IDF와 Logistic Regression의 최적 파라미터를 탐색합니다.

튜닝 대상 파라미터: - TF-IDF: max_features, ngram_range, min_df - Logistic Regression: C (정규화 강도), solver, class_weight

Code 
def objective(trial):
    """Optuna 목적 함수: 검증 세트 F1-Score 최대화"""

    # TF-IDF 파라미터
    max_features = trial.suggest_int('max_features', 1000, 10000, step=1000)
    ngram_max = trial.suggest_int('ngram_max', 1, 3)
    min_df = trial.suggest_int('min_df', 1, 5)

    # Logistic Regression 파라미터
    C = trial.suggest_float('C', 0.01, 10.0, log=True)
    solver = trial.suggest_categorical('solver', ['lbfgs', 'saga'])
    class_weight = trial.suggest_categorical('class_weight', [None, 'balanced'])

    # TF-IDF 변환
    vectorizer = TfidfVectorizer(
        max_features=max_features,
        ngram_range=(1, ngram_max),
        min_df=min_df,
        max_df=0.95,
        sublinear_tf=True
    )
    X_train_vec = vectorizer.fit_transform(X_train)
    X_val_vec = vectorizer.transform(X_val)

    # 모델 학습
    model = LogisticRegression(
        C=C,
        solver=solver,
        class_weight=class_weight,
        max_iter=1000,
        random_state=42
    )
    model.fit(X_train_vec, y_train)

    # 검증
    y_pred = model.predict(X_val_vec)
    return f1_score(y_val, y_pred, average='weighted')

# Optuna 최적화 실행

🔍 학습 포인트 #6: 앙상블의 효과

앙상블이 효과적인 이유: 1. 다양성: 서로 다른 모델의 강점을 결합 2. 안정성: 개별 모델의 오차가 상쇄됨 3. 일반화: 과적합 위험 감소

Voting 방식: - Hard Voting: 다수결 (각 모델의 예측 클래스로 투표) - Soft Voting: 확률 평균 (각 모델의 예측 확률 평균) → 일반적으로 더 좋음

⚠️ 주의: 앙상블이 항상 최선은 아닙니다. 추론 시간이 증가하고, 해석이 어려워집니다.

def get_top_features(model, vectorizer, class_idx, top_n=15):
    """특정 클래스에 대해 가장 중요한 단어 추출"""
    feature_names = vectorizer.get_feature_names_out()
    coef = model.coef_[class_idx]

    # 가장 높은 계수를 가진 단어들 (양의 방향)
    top_positive_idx = coef.argsort()[-top_n:][::-1]
    top_positive = [(feature_names[i], coef[i]) for i in top_positive_idx]

    # 가장 낮은 계수를 가진 단어들 (음의 방향)
    top_negative_idx = coef.argsort()[:top_n]
    top_negative = [(feature_names[i], coef[i]) for i in top_negative_idx]

    return top_positive, top_negative
